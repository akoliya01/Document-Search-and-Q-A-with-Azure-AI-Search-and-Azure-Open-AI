# DocSearchPOC
A Proof of Concept using Azure AI Search and Azure OpenAI to search documents and provide natural language answers.

## Setup
1. Replace the vaule in  `app/config.py` & `.env` with your Azure(OPEN AI and AI Search) credentials.
2. Install dependencies: `pip install -r requirements.txt`
3. Run locally: `python -m app`
