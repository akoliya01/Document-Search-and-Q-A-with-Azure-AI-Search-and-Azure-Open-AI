# DocSearchPOC
A Proof of Concept using Azure AI Search, Azure OpenAI, and Azure App Service to search documents and provide natural language answers.

## Setup
1. Configure `app/config.py` with your Azure credentials.
2. Install dependencies: `pip install -r requirements.txt`
3. Run locally: `python -m app`
4. Deploy to Azure App Service using the Azure CLI.
